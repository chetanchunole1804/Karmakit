# 🌟 KarmaKit – Customizable React UI Component Library

**KarmaKit** is a sleek, customizable, and developer-focused React component library powered by TypeScript. Designed with flexibility, clean architecture, and balance in mind, it helps frontend developers build beautiful and reusable components that just work.

> 🧘 Build with balance. Design with intention.

---

## 📌 Project Status

🚧 **Currently Working On It**  
📦 **Work in Progress (WIP)** – Core structure, components, and documentation are actively being developed. Early adopters welcome.

---

## 🚀 Features

- 🧩 Modular, reusable React components
- 🎨 Tailwind CSS support (optional)
- ⚡ Fast developer experience with TypeScript
- 🔒 Secure monorepo setup
- 🧱 Built-in hooks, utilities, and theming support
- 📦 Ready for NPM publishing
- 🔍 Docs and component preview via Next.js

## 📚 Usage

```bash
import { Button } from "karmakit";
export default function App() {
  return <Button label="Click me" />;
}
```
## 🛠️ Local Development

- To run and test locally:
```bash
git clone https://github.com/chetan-chunole/karmakit.git
cd karmakit
npm install
cd apps/docs
npm run dev
```
